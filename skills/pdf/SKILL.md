# PDF Processing Skill

You can read, extract text from, and create PDF files using this skill.

## Available Operations

- **Read PDF**: Extract text content from a PDF file
- **Create PDF**: Generate a new PDF from text or markdown content
- **Merge PDFs**: Combine multiple PDF files into one

## Usage Guidelines

1. Always specify the full file path when working with PDFs
2. For large PDFs, consider extracting specific page ranges
3. Preserve formatting when extracting text from structured documents
